# ExcelLearn — правила работы

Анимированный курс Excel для сотрудников компаний Казахстана. Программа — по книге У. Уинстона «Microsoft Excel:
анализ данных и бизнес-моделирование», но **сюжеты, данные и тексты свои** (тенге, города и филиалы РК, ТОО/ИП,
местные имена). Подробно: [SPEC.md](SPEC.md), разбор каждой главы — `content/sources/chNN.md`.

## Главное правило

**Всё, что показывает книга, — анимацией в плеере**, не текстом. Если плееру не хватает возможности (окно Excel,
меню, вкладка, действие) — доработать движок, а не упрощать урок. Анимация — главное преимущество перед книгой.

## Как устроен контент

- Курс: `content/course.yaml` (главы). Уроки: `content/lessons/NN-MM-*.yaml`. Задания: `content/exercises/chNN.yaml`.
- Глава = «Теория к главе» (текст без плеера, `content/theory/chNN.yaml`) → вводный урок `NN-00-*.yaml`
  (`order: 0`) → уроки → задания. Генераторы: `scripts/content/gen_theory.py`, `gen_intros.py`.
- Картинки теории — кадры окна Excel: кадр описан мини-уроком (лист + действия + `expect`), снимает его
  `uv run python manage.py theory_frames` (нужен `pnpm --dir player build`) в `static/theory/`. Правка YAML
  кадра → переснять, иначе `lessons_check` упадёт.
- Урок = лист (+ `sheets`, `names`) + шаги с действиями + `expect` (ответы, посчитанные **независимо** на Python).
- Каждый урок: «Ситуация» → шаги → «Частая ошибка» (где уместно) → «Что запомнить» + «На работе пригодится».
- Тексты: `{fn:VLOOKUP}` → «ВПР», `{f:=SUM(A1,B1)}` → формула на языке ученика. В `say` — только `{fn:}`.
- Задание: условие, подсказка, частая ошибка, лист, `solution` (формулы, `fill`, `names`), `expect`. На сайте —
  два файла: «…_задание.xlsx» (жёлтые ячейки) и «…_решение.xlsx».
- **Таблица урока и задания — с A1**: без пустых строк сверху и столбцов слева (иначе окно Excel в плеере выше
  и шире, чем нужно). Адреса в текстах (`<code>`, `{f:…}`, «строки 3–8», «столбец D», адреса словами в `say`) —
  тоже от A1. Проверяет `lessons_check`.
- Ширина листа урока ≤ ~770 px (плеер добавляет справа ещё столбец 64 px); курсор не должен уходить за край сцены
  (плеер пишет предупреждение, e2e его ловит).
- Главы собираются скриптом-генератором (данные + ответы на Python → YAML) в `scripts/content/genNN.py`; образец —
  `scripts/content/gen_ch06.py` (+ `exercises_ch06.py`). Генератор хранится в репозитории, а не во временной
  папке. Разряды в числах — отдельной функцией, не заменой запятых во всей строке.

## Порядок работы над главой

1. Прочитать текст главы, сказать, чего не хватает плееру, доработать движок с тестами («анимация ≡ перемотка»).
2. Уроки и задания на казахстанском материале; ответы посчитать отдельно.
3. Проверки (все должны пройти):
   ```
   uv run python manage.py lessons_check
   pnpm --dir player lessons:verify
   uv run python manage.py exercises_dump | pnpm --dir player exercises:verify
   uv run python manage.py theory_dump | pnpm --dir player theory:verify
   pnpm --dir player typecheck && pnpm --dir player lint && pnpm --dir player test
   uv run ruff check . && uv run ruff format --check . && uv run pytest -q
   pnpm --dir player build && uv run pytest e2e -q
   ```
   Полный e2e (~5 мин, все уроки) — один раз перед коммитом главы; по ходу работы — только изменённые уроки:
   `uv run pytest e2e/test_lessons_play.py -q -k "<id урока>"`.
4. Посмотреть ключевые шаги на кадрах анимации (Playwright + Edge) — по одному кадру на новое окно или действие.
5. Открыть файлы решений в настоящем Excel (COM из PowerShell) и сверить ответы; спорное поведение функций
   сверять с Excel, а не с библиотекой (так нашлись двоичный поиск ВПР и ИНДЕКС по строке).
6. Заметки в `content/sources/chNN.md`, коммит.

## Экономия токенов

- Скриншоты — самое дорогое в контексте: проверять тестами, кадры снимать только для новых окон и действий
  (по одному на итог), для правок дизайна — один-два кадра, не серию.
- Файлы читать кусками (нужные строки, `grep`), а не целиком; большие YAML уроков не выводить полностью.
- Тяжёлые проверки (полный e2e) — один раз в конце задачи; по ходу — только затронутое.
- Новая задача — новая сессия (`/clear`): правила проекта здесь, история не нужна.

## Окружение (Windows)

- Python: `py -m uv run …` (в активированном `.venv` — просто `python …`). Node 24, pnpm 10.
- Запуск: `pnpm --dir player build; pnpm css; python manage.py runserver`.
- **Никогда не удалять `db.sqlite3`.** Для экспериментов — копия базы и `DATABASE_URL=sqlite:///…`.
- Озвучка выключена (`NARRATION_ENABLED=false`) до решения в конце проекта; тексты `say` всё равно пишем.
- Отвечать пользователю по-русски.
