# Implementation Plan: ExcelLearn v1

Источник требований: [SPEC.md](../SPEC.md) (утверждено 2026-10-08). Задачи с критериями приёмки: [todo.md](todo.md).

## Overview

Django-сайт с одним курсом по книге Уинстона, разбитым на главы. Каждый урок — YAML-файл, который проигрывает TypeScript-плеер: симуляция Excel, курсор, перемотка по шагам, озвучка. Ученики регистрируются (ФИО, email, телефон, согласие на обработку ПДн), сайт сохраняет их прогресс и настройки. Хостинг — VPS в Казахстане, Docker Compose.

## Architecture Decisions

- **Порядок сборки по карте модулей:** `lesson-format` → `player` → `catalog` → `narration` → `accounts` → `progress`, `preferences` → деплой.
- **Плеер — самая рискованная часть, поэтому он идёт вторым.** Сначала доказываем, что YAML-урок воспроизводится не хуже прототипов и перематывается, и только потом строим сайт вокруг.
- **Своя модель `User` создаётся в первой же миграции** (задача 2). До этого `migrate` не запускаем, иначе замена модели пользователя станет дорогой.
- **Импорт из файлов книги.** В папке проекта лежат материалы книги: `Templates/` (≈260 шаблонов `*temp.xlsx`), `Practice Files/` и `Solution Files/`. Команда `lesson_import` (задача 7) берёт данные листа из шаблона, а значения `expect` из готового решения (`*final.xlsx`). Таблицы не перепечатываются вручную, и данные урока совпадают с книгой. Нужна зависимость `openpyxl`, используется только в команде, не в рантайме.
- **Материалы книги не попадают в git** (`.gitignore`), потому что это защищённые авторским правом файлы. В репозиторий идут только наши YAML-уроки.
- **Озвучка до аккаунтов.** Она нужна для приёмки уроков, а аккаунты от неё не зависят. Пока нет ключа Yandex, работаем с провайдером `silent`.

## Parallelization

- После T1–T4 **плеер (T8–T16)** и **бэкенд (T17, T22, T23)** независимы и могут идти параллельно.
- T19–T20 (серверная часть озвучки) не зависят от плеера.
- Работа идёт последовательно, по одной задаче, с проверкой после каждой. Параллелить имеет смысл, только если ускорение важнее простоты ревью.

## Risks and Mitigations

| Риск | Влияние | Митигация |
|---|---|---|
| `fast-formula-parser` не поддерживает нужную функцию (например, `FORMULATEXT`) или ведёт себя иначе, чем Excel | Высокое | В T8 проверяем функции из глав 1–3; недостающие регистрируем как кастомные; `lessons:verify` сверяет с `*final.xlsx` |
| Перемотка расходится с полным прогоном (скрытое состояние в `animate`) | Высокое | Правило: `animate()` меняет модель только через `apply()`; property-тест «seek(N) ≡ прогон до N» для каждого урока |
| Браузеры блокируют автозапуск аудио | Среднее | Воспроизведение начинается только по клику «Начать урок»; при отказе — пометка «звук недоступен», урок идёт без звука |
| Синтезатор неверно читает адреса и формулы | Среднее | Отдельное поле `say` со словами вместо символов; словарь произношений в builder |
| Нет доступа к Yandex Cloud / оплаты из РК | Среднее | Интерфейс `TTSProvider`; режим `silent` не блокирует разработку; запасной провайдер подключается одной задачей |
| `preservesPitch` по-разному работает в Safari | Низкое | Ограничить скорость озвучки до 2×; e2e в Chromium и WebKit |
| Структура `*temp.xlsx` разная от главы к главе | Среднее | `lesson_import` переносит только значения и базовый формат; остальное правится в YAML вручную |
| Требования закона РК о ПДн | Среднее | Сервер и бэкапы в РК; согласие с версией; ПДн не уходят во внешние сервисы; текст согласия согласовать с юристом до запуска |
