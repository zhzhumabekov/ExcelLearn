# Корневые сертификаты ЦС компании

Если сеть компании проверяет HTTPS (SSL-инспекция: прокси или брандмауэр подписывает сайты своим сертификатом),
положите сюда корневой сертификат компании в формате PEM с расширением `.crt` — сборка образа (npm, uv) будет ему
доверять. Файлы `*.crt` в git не попадают. Подробно — docs/deploy.md, шаг 3.
